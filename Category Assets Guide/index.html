How to make them (Gemini)

  1. Go to the Production tab and pick the type you’re creating.
  2. Open the Gemini app at https://gemini.google.com/app and tap Create image.
  3. Paste the prompt from the template on this page and generate the image.
  4. In Photoshop, knock out the background so the cutout works on light and dark mode.
  5. Save as PNG and upload it on that Production row.

Prompt you can paste into Gemini

Only three lines need your values: category, type, and color scheme (each in brackets below). Paste the rest of the prompt unchanged for every type. 

We are building a matched set of category tiles — each image must feel like the same brand / theme as the others.

You only fill in these three lines:
- Category: [CATEGORY NAME — e.g. Women’s fashion]
- Type: [TYPE NAME — e.g. Outerwear, Tops, Sports bras]
- Color scheme (2–4 colors the whole set shares): [e.g. oatmeal, warm white, washed indigo, soft black]

What to show for this tile (fixed instructions — do not change this block):
- Depict exactly what the category and type names imply: a single, believable product (or a small coherent set only when the type clearly calls for multiple items—e.g. accessories). Do not invent unrelated categories of goods.
- Default to one main product, centered, top-down, filling a comfortable portion of the frame. If multiple products are appropriate, use at most five distinct objects, each clearly readable, evenly spaced, in a simple arrangement (single row, gentle arc, or loose grid)—nothing crowded, nothing touching the frame edges.
- Avoid vague hero shots: show the actual product forms (silhouette, layers, hardware) you would expect for that type in e-commerce.

Shot & composition:
- Simple product shot, top-down / overhead view, camera straight above, product centered.
- If you combine multiple products or props in one frame, maximum 5 objects total, clearly separated (prefer fewer).

Set / theme rules:
- Treat this as one set: use similar tones and stay inside the color scheme you named above (do not introduce a new accent color).
- Flat, even lighting. Absolutely no shadows — no drop shadows, no cast shadows, no contact shadow, no ground plane or horizon.
- The product(s) should look like they were clipped out in Photoshop and placed floating in empty air — not on a floor, table, or lifestyle scene.

Technical:
- Create in high resolution.
- Output must be exactly 1:1 (square) aspect ratio.
- Clean edges, catalog-sharp clarity suitable for UI thumbnails.
- Background: solid light gray #f3f3f3 filling the entire frame edge-to-edge (or full transparency if you need alpha — state which you used).

If the model drifts, add: no vignette, no logos or text, no hands or mannequins unless you explicitly want them.

Production — category assets

One hi-res 1×1 asset per type. Set Status to Not Started, Needs Approval, or Complete. Use Add at the bottom of the list for new types or categories (with optional description). Open a category accordion to work through items.
